# MAVI CLASSES Website

A responsive, single-page website for MAVI CLASSES, Meerut.

## Included
- Responsive desktop, tablet and mobile layout
- Home, About, Courses, Why MAVI, FAQs and Contact sections
- Course category filters and enquiry forms
- Basic client-side form validation
- Enquiries stored in the visitor's browser under `maviClassesEnquiries`
- SEO title, description, keywords and Open Graph metadata

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site. The public URL will be shown in Settings → Pages.

## Before accepting real enquiries
The forms currently save data only in the visitor's own browser. They do **not** send submissions to MAVI CLASSES, and there is no admin dashboard or central student database yet. Connect a secure backend or trusted form service, add server-side validation and spam protection, and configure authorised admin access before using this for real admissions. Never put passwords, API secrets or private keys in this repository.

## Details to customise
Update the institute's verified phone number, WhatsApp number, email, complete street address, faculty, actual course availability, fees, batch timings, photos and results when supplied. Do not publish unverified rankings or claims such as “No. 1” as established facts.
